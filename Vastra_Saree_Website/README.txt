VASTRA — THE SAREE EDIT
A responsive saree marketing and demo shopping website.

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or open it in VS Code and use Live Server.
4. Internet is required for Google Fonts and the remote saree photos.

FEATURES
- Responsive desktop and mobile layout
- Saree collection cards and category filters
- Add-to-bag and remove-from-bag interactions
- Cart subtotal calculation
- WhatsApp enquiry checkout demo
- Newsletter form demo
- About/story, craft, testimonials and contact sections

BEFORE USING FOR A REAL BUSINESS
- Replace VASTRA with your business name and logo.
- Replace demo product names, prices, descriptions and photos with actual catalogue details.
- Replace +91 98765 43210 in index.html and script.js with the business WhatsApp number.
- Replace hello@vastra.example and social links with real contact details.
- Connect a payment gateway and backend for real orders. This is a front-end demonstration site; it does not process payments or save customer orders.
